🔐 Encryption Details

Customer Names Encryption: अगर आपने app में अपना नाम register किया है, तो वह AES-256-GCM encryption के साथ सुरक्षित रहता है।

How it works:
  • आपका नाम device-specific key से encrypt होता है
  • Encryption key आपके Device ID (HWID) से derive होती है
  • Same name different devices पर different encrypted values बनाता है
  • Backward compat: Legacy v1 salt भी auto-decrypt होती है

🔄 Update के बाद पुराना Version दिख रहा है

Cause: Service Worker अभी तक new version पर switch नहीं हुआ।

1 Hard Refresh करें
Ctrl + Shift + R दबाएँ (Windows/Linux)
Cmd + Shift + R दबाएँ (Mac)
2 Service Worker Unregister करें
DevTools खोलें (F12) → Application tab → Service Workers → Unregister click करें → Page reload करें।
3 Cache Clear करें
DevTools → Application → Storage → Clear site data.
Console check: navigator.serviceWorker.controller.scriptURL run करें — current SW version confirm होगी।

💾 Application Startup Fail (Production)

Error: "Configuration Error: NAME_ENCRYPTION_SECRET is not configured"

Cause: Production build में encryption secret missing है।

Fix: This is a security measure — app production में unencrypted data store नहीं करता।

  • Vendor से contact करें
  • Reinstall करें (proper .env के साथ)
  • Error Code note करें: ENC_SECRET_MISSING
